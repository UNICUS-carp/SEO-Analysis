# GA4イベントトラッキング実装プロジェクト
## 株式会社サンヒルズ Webサイト

---

## 📋 プロジェクト概要

このプロジェクトは、株式会社サンヒルズのWebサイト（https://sun-hills.info/）における**売上貢献度を正確に測定**するためのGA4イベントトラッキング設定を提供します。

### 重要な発見
✅ **Google Tag Manager (GTM-KJKF7M9) が既に導入済み**

これにより、コード変更なしでGTM経由での柔軟なイベント設定が可能です。

---

## 🎯 ビジネスゴール

1. **商品サイトへの誘導効率の測定**
   - 歩行ケアプロソックス
   - おうちでできる歩行ケア

2. **ブログコンテンツの売上貢献度の測定**
   - セルフケア記事
   - トピックス

3. **ユーザージャーニーの可視化**
   - 流入元 → コンテンツ閲覧 → コンバージョン

4. **ROI向上のためのデータドリブン改善**

## 📞 サポート・質問

### よくある質問

**Q: GTMを初めて使うのですが大丈夫ですか？**
A: はい！`quick-start-guide.md` は初心者向けに作成されています。

**Q: どのイベントから設定すべきですか？**
A: レベル1の3つのイベント（商品・整骨院クリック）から始めてください。

**Q: 設定にどれくらい時間がかかりますか？**
A: 最初の1イベントは30分、全8イベントで2-3時間程度です。

**Q: テスト環境は必要ですか？**
A: GTMのプレビューモードがあるため不要です。本番環境で安全にテスト可能です。
